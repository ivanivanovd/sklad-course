# Секции сайта Майи для импорта в Tilda Zero Block

Каждый HTML-файл — отдельная секция. CSS уже находится внутри файла, отдельно загружать таблицу стилей не нужно. Загружайте файлы по одному.

## Порядок секций

1. `01-hero.html` — первый экран. Кнопка «Обсудить занятия» набирает номер 8 902 822-21-22; HTML-импорт Tilda не переносит JavaScript, поэтому кнопка сделана прямой ссылкой на телефон.
2. `02-about.html` — обо мне и фото.
3. `03-audience.html` — кому подойдут занятия и нарисованный переход.
4. `04-format.html` — индивидуально, Zoom, 60 минут.
5. `05-lesson.html` — как проходит урок и волнистая граница.
6. `06-faq.html` — частые вопросы.

## Импорт каждой секции

1. На странице Tilda добавьте отдельный Zero Block для секции.
2. Откройте Zero Block → меню `…` → `Import from HTML`.
3. Загрузите соответствующий файл и нажмите `Prepare to Import`.
4. Для пустого Zero Block выберите `Арборд` (настройки файла применятся к артборду). Если добавляете секцию внутрь уже существующего Zero Block, выбирайте `Группа`. Не используйте `Группа, Заменить всё`, если не хотите удалить содержимое текущего блока.
5. Повторите для остальных файлов и расположите Zero Blocks в указанном порядке.

После импорта проверьте адаптивность на мобильном брейкпоинте: Tilda преобразует HTML/CSS в свои редактируемые слои, поэтому отдельные размеры и позиции могут потребовать ручной настройки.
